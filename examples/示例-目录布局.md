# 示例，未部署

这是目录分类示例，不是当前机器状态。实际路径、引用和迁移结果填写到 local/，不要将真实机器信息写回此文件。

| 类型 | 示例目标 | 保留要求 |
|---|---|---|
| 开发工具数据 | <DataRoot>/DevTools/<原工具目录名> | 同步环境变量、工具配置和入口 |
| 应用用户数据 | <DataRoot>/UserData/.example-app | 保留前导点与原名，验证应用 |
| 独立容器配置 | <DataRoot>/Docker/services/<服务名> | 分别保留容器与持久化数据 |
| 私有连接信息 | local/private.json | 受限权限，不提交 Git |
| 本次临时备份 | backups/<本次操作名>/ | 验证完成后及时清理 |

目录归类不等于服务编排；移动前应核对平台和全部实际引用。
