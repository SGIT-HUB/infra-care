# Windows 磁盘清理与迁移

帮助用户释放磁盘空间、迁移适合迁移的数据，并留下可验证、可回滚的本机记录。所有具体路径与状态都以当前机器的只读检查为依据。

## 先确定当前机器与任务

- 用户只要求分析时，完成盘点与方案；实际变更按当前请求和已有授权执行。创建或阅读本技能本身不授权清理磁盘。
- 读取用户指定的维护档案；在 infra-care 中先核对 local/machine.json，再读取 local/维护档案.md。档案不存在也能独立使用本技能。
- 将档案中的机器标识、用户目录、磁盘与当前环境比对。来源不明或来自另一台机器时，仅作为历史案例；用户名相同也不能证明是同一台机器。
- 复制到新机器时遵循项目的机器识别与档案流程：仅在授权范围内替换旧本机维护记录，不能清理应用数据；不复制旧机器的“已验证”“已迁移”状态，不预设目标盘符。

以下仅收集当前环境，不会修改文件：

```powershell
[PSCustomObject]@{
    Machine = $env:COMPUTERNAME
    UserProfile = $env:USERPROFILE
    SystemDrive = $env:SystemDrive
    PowerShell = $PSVersionTable.PSVersion.ToString()
}
Get-CimInstance Win32_LogicalDisk -Filter 'DriveType=3' |
    Select-Object DeviceID, FileSystem, Size, FreeSpace
Get-ChildItem -LiteralPath $env:USERPROFILE -Directory -Force |
    Select-Object FullName, Attributes, LinkType, Target
```

## 按任务推进

| 任务 | 必须得到的结果 |
|---|---|
| 空间盘点 | 各卷可用空间、主要占用、联接实际落盘位置、无法读取的范围 |
| 清理建议 | 每个候选的用途、预计释放空间、是否可再生成、授权与占用情况 |
| 数据迁移 | 经核实的源目录、目标目录、备份位置、应用支持方式、验证与回滚方案 |
| 执行变更 | 逐项记录实际结果；复制或改名失败后停止后续切换 |
| 回滚 | 判断切换后是否有新增或修改数据，选择保留最新数据的恢复路径 |
| 归档 | 记录本机身份、实际路径、验证时间、保留副本与待办事项 |

先查看一级目录，再针对大目录深入；容量扫描不跟随重解析点（ReparsePoint），另列它们的目标，避免重复统计或误算为系统盘占用。扫描有访问失败时注明覆盖范围。逻辑文件大小是估算，清理效果以所在卷的实际可用空间变化复核。

优先使用应用提供的缓存清理、数据位置或迁移功能。缓存、日志也需确认保留价值；下载、数据库、模型、项目、认证数据和备份不能仅凭目录名判断为可删除。

## 发生实际变更前

迁移、删除备份、修改联接或回滚前，读取 [迁移与回滚流程](references/迁移与回滚流程.md)。它包含路径核验、内部联接、失败恢复和有新增数据时的回滚要求。

- 只迁移已识别且应用支持的具体数据目录。整个用户配置文件、AppData、Windows、Microsoft、Packages、Programs、Temp 等目录不作为整体联接迁移对象。
- 活跃的数据库、虚拟磁盘、云同步数据和 AI 工具自身运行目录需先停用相关写入者，并采用其支持的迁移方式；不能在当前 AI 运行中迁移它自己的状态目录。
- 已授权的具体操作无需重复询问；永久删除必须有覆盖具体对象的明确授权。尚未授权时，先给出可审阅的路径、用途和影响。
- 发现源或目标已是联接、目标有未知内容、备份重名或文件仍被占用，先核实；不以覆盖或强删继续流程。

## 输出与维护记录

结论先说明已经完成的动作和实际释放空间，再列未完成项。未执行应用验证就写“待验证”，不能把复制成功当作迁移成功。

维护记录存放在用户指定的长期文档位置，至少包含：机器名与用户目录、检查时间及范围、源路径／实际目标／备份映射、变更前后可用空间、内部联接、验证结果、当前有效数据副本、回滚条件和待清理对象。只更新实际检查过的结论，不写入密钥或令牌。

常见误用：照搬旧机器盘符；把联接目标再次计入源盘；跳过内部链接检查；切换后有新数据却直接恢复旧备份；把迁移成功与立即删除备份绑定。
