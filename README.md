# infra-care

面向 Windows、Linux 和 macOS 的本机与设施维护知识库。保存可复用的维护技能、使用约定和脱敏示例；每台机器的真实状态单独保存在本地。

目前提供跨平台维护入口、Windows 磁盘专项流程，以及必须显式启用的 ClamAV 专项技能。Linux、macOS 的机器识别已有约定，具体应用维护仍应按当前平台核实，不能将 Windows 操作照搬过去。

## 目录

| 目录 | 用途 | 提交到仓库 |
|---|---|---|
| `skills/` | 通用维护技能及参考材料 | 是 |
| `examples/` | 标明“示例，未部署”的模板 | 是 |
| `docs/` | 使用约定 | 是 |
| `local/` | 当前机器身份、维护档案和偏好 | 否 |
| `backups/` | 当前变更的临时备份，验证完成后及时清理 | 否 |

## 使用

1. 将本仓库克隆或复制到本机，先读取 [AGENTS.md](AGENTS.md)。
2. 使用 [本机综合维护技能](skills/machine-maintenance/SKILL.md)，按 [机器识别与档案](skills/machine-maintenance/references/机器识别与档案.md) 核对机器身份，再读取或建立 `local/` 档案。
3. Windows 磁盘任务按需读取 [磁盘专项技能](skills/windows-disk-maintenance/SKILL.md)。
4. 维护后更新实际路径、连接信息位置和验证结果，区分“建议”“已写入”和“已生效”。

支持个人技能目录的工具可以安装所需的完整技能文件夹；也可以直接读取仓库中的 SKILL.md。安装方式不等同于授权执行其中的变更。安装副本可用仅保存在本机的 `local-root.txt` 记录仓库根目录；该定位文件不能提交。

新机器优先克隆仓库，不携带旧的 `local/`。若复制整个目录，必须先识别机器，再清理确认属于旧机器的维护记录并建立新档案。不会清理应用、数据库或仓库外数据。

## ClamAV 默认关闭

默认不加载 ClamAV 技能正文、不安装程序、不更新病毒库、不扫描，也不创建后台服务或计划任务。只有用户明确要求启用或使用 ClamAV 后，才读取 `skills/clamav-maintenance/SKILL.md` 并按指定范围执行。技能元数据关闭隐式调用。

## 公开仓库规则

**公开仓库禁止提交敏感信息。** 不提交真实本机档案、密码、令牌、私钥、MAC、系统机器标识、连接凭据、原始日志或扫描结果。`.gitignore` 是第一道过滤，提交前还必须检查实际暂存内容和 Git 历史。详见 [安全规则](SECURITY.md)。

示例统一放 `examples/`，文件名以“示例-”开头，使用明显占位值；示例不代表已部署。真实凭据仅保存在本机受限位置。
