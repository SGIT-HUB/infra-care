# 使用约定

## 通用能力与本机状态

skills/ 保存跨机器可复用的方法，local/ 保存当前机器事实。新会话读取当前机器身份与对应记录，不依赖之前的聊天，也不把档案当作执行授权。

只记录实际执行和验证结果。安装、写入配置、服务就绪和连接验证是不同状态。用户只要求部署与记录时，不额外生成维护命令或编排平台。

## 平台边界

machine-maintenance 提供 Windows、Linux、macOS 的共同入口和机器身份流程。windows-disk-maintenance 仅用于 Windows；其他平台应根据实际系统和官方说明选择其原生机制，不套用 Junction、Windows 路径或 PowerShell 清理命令。

现有 Windows 流程已经在实际维护中使用；Linux 和 macOS 的专项应用配置仍需按任务验证，不承诺未测试的软件支持。

## 备份与示例

文档改动临时备份统一放 backups/，检查迁移结果后及时清理。应用数据库或用户数据的回滚备份不因文档更新而删除。

examples/ 中的文件均为“示例，未部署”。使用模板时在 local/ 创建当前机器的真实记录；不要把填入真实信息的模板保存回公共 examples/。

## 技能安装

可复制需要的完整技能文件夹到使用工具支持的个人技能目录。若安装副本需要找到仓库，在该安装文件夹创建本地 local-root.txt，内容为当前仓库根目录。定位文件不进入 Git。

ClamAV 技能的 allow_implicit_invocation 为 false。不要将安装技能文件理解为安装或启用 ClamAV 软件。
