# 使用约定

## 通用能力与本机状态

skills/ 保存跨机器可复用的方法，local/ 保存当前机器事实。需要接续实际维护时，先核对当前机器身份再读取对应记录，不依赖之前的聊天，也不把档案当作执行授权。仅整理公共文档时不做机器盘点。

只记录实际执行和验证结果。安装、写入配置、服务就绪和连接验证是不同状态。用户只要求部署与记录时，不额外生成维护命令或编排平台。

## 平台边界

machine-maintenance 提供 Windows、Linux、macOS 的共同入口和机器身份流程。windows-disk-maintenance 仅用于 Windows；其他平台应根据实际系统和官方说明选择其原生机制，不套用 Junction、Windows 路径或 PowerShell 清理命令。

现有 Windows 流程已经在实际维护中使用；Linux 和 macOS 的专项应用配置仍需按任务验证，不承诺未测试的软件支持。

## 软件与设置变更

针对本次任务逐项核对，不把外部工具的整套“优化”预设当作当前机器的目标状态：

- 区分当前实测值、厂商默认值、工具推荐值和用户偏好。读取失败或权限不足记为未知，不推定为关闭、未安装或需要修复；当前状态已满足需求时不重复变更。
- 核对适用的系统版本、构建、用户或机器范围及依赖。列明本次会影响的应用、服务和生效条件；已有授权覆盖时继续执行，依赖不在范围内时不自动补齐或扩大操作。
- 安装或升级前确认软件现由哪个渠道管理，再核对包标识、来源、版本、架构和安装范围，避免同名误选或多个管理器重复接管。请求的安装目录不代表安装器实际采用，安装后复核程序、数据和缓存位置。
- 回退依据使用本机实际变更前状态，必要时保留配置值的类型、原本不存在的状态及服务启动方式。工具声明的默认值或撤销预设不等于本机原值；系统还原点也不能代替应用或数据库备份。回退材料仍按本项目备份约定处理。
- 写入后重新读取配置，并通过对应应用或服务验证结果；需重启或注销才生效时，记录待生效及所需中断范围，不把命令退出成功等同于运行验证通过。

## 命令与界面工具选择

优先使用已有的专用接口、官方 CLI 或平台原生查询完成任务；需要界面操作时，再使用当前会话已提供的界面工具。已有能力足够时，不为完成同一任务再安装一套 MCP 服务。

- 先确认目标应用、窗口及当前控件或截图，再执行小步操作并重新观测。界面变化后刷新目标定位，不盲用旧坐标或元素编号；窗口出现和点击返回成功都不能单独证明操作已生效。
- 观测只取当前任务所需范围。控件树不可用、输入定位失败、权限不匹配或用户接管时，停止相关输入并重新核对，不继续向其他窗口点击或输入，也不将失败报告为成功。
- 对可能挂起的查询设合理超时，区分超时、非零退出和空结果。清理由本次诊断创建的子进程时核对归属；不能顺带终止原有应用或服务，重启仍须符合本次任务授权。

## 外部项目的学习与取舍

以下仅为查阅上游文档或源码后的设计借鉴，本仓库未因此安装这些工具，也不据此宣称已完成本机运行验证。具体设置与工具参数在实际任务中按所用版本复核。

| 项目与查阅位置 | 本仓库采用的思路 | 取舍 |
|---|---|---|
| [Winhance 设置定义](https://github.com/memstechtips/Winhance/blob/main/src/Winhance.Core/Features/Common/Models/SettingDefinition.cs)、[状态结果](https://github.com/memstechtips/Winhance/blob/main/src/Winhance.Core/Features/Common/Models/SettingStateResult.cs) | 适用构建、依赖与偏好分开描述；读取是否成功独立于设置值 | 用现有文档表达必要判断，不复制完整设置目录或实现配置引擎 |
| [Windows-MCP 桌面实现](https://github.com/CursorTouch/Windows-MCP/blob/main/src/windows_mcp/desktop/service.py)、[工具与输入失败说明](https://github.com/CursorTouch/Windows-MCP#readme) | 状态观测与操作区分，目标刷新，输入失败显式返回 | 借鉴操作与验证方法，不默认安装服务、开放远程控制或改变现有客户端配置 |
| [WinUtil 设置定义](https://github.com/ChrisTitusTech/winutil/blob/main/config/tweaks.json) | 描述、操作和撤销信息集中在同一主题 | 保留本机实测原值，不套用整套预设或把声明的原值当作备份 |
| [WinGet 安装选项](https://learn.microsoft.com/en-us/windows/package-manager/winget/install) | 包标识、来源、版本、架构和安装范围分别核对 | 按软件已有渠道选择工具，安装退出成功后继续核实实际位置与运行状态 |

## 备份与示例

本项目安装、配置和目录整理的临时备份、下载与解压暂存统一放 backups/，验证完成后按授权及时清理。不要把旧安装备份长期散放在应用数据根目录。实际业务备份、尚未完成验证的回退数据不因文档更新而删除。

examples/ 中的文件均为“示例，未部署”。使用模板时在 local/ 创建当前机器的真实记录；不要把填入真实信息的模板保存回公共 examples/。

## 技能安装

可复制需要的完整技能文件夹（含 references/）到使用工具支持的个人技能目录。若安装副本需要找到仓库，在该安装文件夹创建本地 local-root.txt，内容为当前仓库根目录。定位文件不进入 Git。

仓库是通用知识的维护源，安装副本不自动同步。用户要求更新安装副本时，先核对差异和自定义内容，再同步完整技能及引用；已合并的旧入口不继续作为第二份维护源。不要直接覆盖或删除安装副本中的独立内容。

ClamAV 技能的 allow_implicit_invocation 为 false。不要将安装技能文件理解为安装或启用 ClamAV 软件。

采用 [目录归类与迁移](目录归类与迁移.md) 的用途分类和引用核对要求。实际凭据使用本机受限的 local/private.json；它不参与公开提交。
