# 目录归类与迁移

目录整理的目标是让用途、数据位置和维护记录一致，不能仅把文件夹搬到另一处而保留失效引用。

## 按用途归类

以下为 Windows 数据根目录的示例布局；数据根目录由当前机器决定，不硬编码盘符。

```text
<DataRoot>/
├─ DevTools/              开发工具的数据、缓存和用户安装入口
│  ├─ Go/
│  ├─ uv/
│  ├─ vfox/
│  ├─ npm/
│  ├─ pnpm/
│  ├─ pip/
│  ├─ Bun/
│  └─ Maven/
├─ UserData/              应用的用户数据，保留原目录名
│  └─ .example-app/
├─ Docker/
│  ├─ wsl/                已配置的 Docker 数据磁盘
│  └─ services/           各独立容器的外置配置、站点和证书
└─ WSL/                   独立发行版磁盘及交换文件
```

程序与 SDK 安装目录和上述数据目录分开管理。保留应用原目录名称、大小写和前导点，不擅自给原数据文件夹改名。用户明确排除的自建目录保持原样。

Linux、macOS 使用其平台原生目录和应用支持的存储设置；不将此示例原样套用到系统目录。实际布局和已迁移状态只记录在 local/，建议布局不得写成已完成。

## 迁移时同步真实引用

- 开发工具：检查环境变量、PATH、Shell Profile、包管理器设置、SDK 管理器配置及目录联接。保留正在使用的工具入口，迁移后实际运行命令验证。
- 用户数据：先退出应用和后台写入者。目录名包含“cache”不代表整棵目录可删除，需区分会话、数据库、登录材料和临时文件。
- Docker：区分镜像与数据卷、外置配置、证书和站点文件。数据卷本就位于引擎数据磁盘中时，只归类有需要的外置配置，不复制第二份数据库目录。
- 独立容器可以拥有统一的配置父目录；目录归类不要求 Compose、统一启停脚本或重新编排。
- 正在使用的 bind mount 改路径通常需要重新创建或重新配置容器。先盘点全部原参数与挂载，按授权安排中断并验证关联服务，不为了目录整齐直接搬动运行中数据。
- 连接与挂载记录同步更新到 local/，实际凭据统一保存在受限的 local/private.json；不改动服务密码来迁移记录文件。

## 备份位置和收尾

本项目执行安装、配置或目录整理产生的临时备份、下载与解压暂存统一位于仓库 backups/ 下的本次操作目录。不要新建常驻的安装备份、stage、extract 或“已验证 SDK 副本”散落在应用数据根目录。

原子切换确需在源目录旁短暂改名时，这只是切换步骤，不是常驻备份位置。需要继续保留的回退内容应归入统一 backups/ 并核对复制结果；应用验证通过且清理在授权范围内时及时清除临时原件和备份。验证未通过时保留可恢复数据，不用“及时清理”要求强行删除。

用户自行管理的数据库定期备份、业务备份不属于本项目的临时整理备份，不能套用上述清理规则。

## 已验证的通用经验

- 复制已有 Junction 或符号链接时保留链接本身，不能展开外部程序目录后误当重复数据。清理含链接的旧副本时，先核对并仅移除链接入口，再处理普通数据。
- 核对复制退出码、关键文件哈希和最终链接位置；对应用数据还要启动应用验证。没有历史数据时如实记录“启动正常，未覆盖历史恢复”，不声称完成不存在的历史验证。
- 备份尚占用源盘时，不能把复制成功记为已释放源盘空间。清理后复核所在卷的实际可用空间，并区分文件逻辑大小和卷空间变化。
- 可重下载的安装包、空解压目录和未被引用的旧 SDK 副本，在核对当前有效安装后按授权清理。旧环境快照或脚本可能唯一时先说明，明确处置后收尾，不永久留下用途不明的备份目录。
- 工具命令可运行不代表所有 IDE、服务和既有终端都已切换环境；按实际使用方式验证，不把仅计划的归类写成完成。
- 修改持久化环境变量不会更新既有进程的环境。旧 IDE、终端及其他自动化会话可能重新创建旧目录；先确认实际写入者退出，再将新增文件合并到新目录，保留较新的有效文件，验证后清理旧入口。仍在运行的构建不强行终止；未完成项写入本机交接记录。
- 应用重装或更名后重新核对程序实际使用的数据路径，不能沿用上一版本的目录结论。用户明确清理旧应用时，区分旧程序数据、共享组件和独立工作区，保留工作区及不属于该应用的内容。
- 从 WSL 集成客户端提交 Docker bind mount 时，使用该客户端实际可见且类型正确的源路径；不要把引擎内部路径当作客户端路径。重建时保留镜像、环境、端口、健康检查、日志策略和命名卷，验证关联入口后清理本次回退容器，不删除其他任务的回退对象。
